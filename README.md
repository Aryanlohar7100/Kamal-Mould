---

## 🌟 Executive Overview

**Kamal Moulds®** (Proprietor: *Mafatlal Manchaji Paradiya*) is an **ISO 20457:2018 Certified** industrial leader specializing in custom injection mould toolings, multi-cavity plastic die moulds, gems candy filling toys, whistle toys, and compostable PLA cutlery. 

This digital catalog web platform provides an interactive, seamless, and mobile-optimized inquiry system for B2B buyers, wholesalers, and confectionery brand partners worldwide.

## ⚡ Key Platform Features

### 🛍 1. Interactive 122+ Item Product Catalog
- **Category Filter Tabs:** Instant client-side filtering across Confectionery Toys, Eco PLA Cutlery, Food Containers, Promotional Items, Moulds & Dies, and Kids Games.
- **Search Engine:** Real-time search by product name, item number, material, or specifications.
- **Grid & List Views:** Toggle between visual card grids and detailed technical list views.

### 📜 2. Official PDF Print Brochure Replica Viewer
- Interactive pagination matching official printed brochure pages (#1 to #122).
- Clear specification callouts (Material, Capacity, Toy Shape, MOQ, P20 Steel Mould specs).

### 📋 3. Dynamic RFQ (Request For Quote) System
- **Cart-Style RFQ Drawer:** Clients can select products, adjust target order quantities (e.g. 5,000 to 100,000+ units), and input custom tooling requirements.
- **Direct WhatsApp Inquiry Generator:** Converts quotes into formatted WhatsApp messages sent directly to company sales (+91 94260 09858).

### 📱 4. 100% Mobile & Touch Optimized
- Swipeable horizontal category tabs on smartphones (`touch-pan-x`).
- Full-width mobile modal and drawer drawers designed for single-hand touch interaction.

## 🚀 Local Installation & Setup Guide

### Prerequisites
- **Node.js**: `v18.0.0` or higher
- **npm**: `v9.0.0` or higher

### Steps

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Aryanlohar7100/Kamal-Mould.git
   cd Kamal-Mould
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173/` or `http://localhost:5174/` in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Preview production bundle:**
   ```bash
   npm run preview
   ```
